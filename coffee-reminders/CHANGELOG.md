# Changelog

## 0.3.0
- Send directly through a USB GSM/LTE modem with a SIM card (no Twilio needed).
- "Send test SMS" and "Check modem" buttons.

## 0.2.0
- Runs as a Home Assistant add-on with a sidebar web page and a built-in schedule.
- Can send through a Home Assistant notify service instead of Twilio.

## 0.1.0
- Command line tool sending reminders through Twilio.
